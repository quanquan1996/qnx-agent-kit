qnx-agent-kit

Give an AI coding agent the scheduler's view of a QNX 8.0 target.

MCP tools · qcc · tracelogger · pidin · priority inheritance

The program: rt_loop.c

threadpriorityjob
control501 kHz control loop — must not stall
uploader30woken by logger, spins 4 ms, never takes the lock
logger10copies shared state under the lock
static sem_t lock;   /* shared by control + logger */
#define LOCK()   sem_wait(&lock)
#define UNLOCK() sem_post(&lock)
Symptom: the control loop "sometimes stalls". The agent is not told why.

The kit: one Python file, 7 MCP tools

qnx_env      check SDP, qcc, target reachability
qnx_image    build / start / stop a QNX 8.0 VM (mkqnximage)
qnx_build    qcc build, diagnostics as JSON
qnx_deploy   scp binary to target
qnx_run      run on target, capture output
qnx_trace    tracelogger on target → decode on host → per-thread summary
qnx_inspect  pidin snapshots: thread states, priorities
+ SKILL.md: QNX rules the agent reads first (e.g. "semaphores don't inherit priority").
